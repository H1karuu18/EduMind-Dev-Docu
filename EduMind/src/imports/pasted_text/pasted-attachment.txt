Additional Design Notes (React + Tailwind CSS + AWS)
All components should be built as reusable React components with clear prop variants — e.g., <Button variant="primary" size="md"> or <Badge status="approved">
Use Tailwind utility classes — no custom CSS unless absolutely necessary. Use @apply sparingly only for complex repeated patterns
All modals use a backdrop blur overlay (backdrop-blur-sm bg-black/40)
All tables are sortable and filterable by default — include filter row in the design
All forms use controlled inputs — design should show the validation state visually (red border + error message below field)
AWS Cognito auth flow — the login screen must account for three flows: email/password (Individual), Google OAuth (Individual), and SSO redirect (Enterprise — routes based on email domain)
Mobile responsive breakpoints — design all screens at 1280px desktop but note which components collapse into mobile-friendly views at 768px (tablet) and 375px (mobile)
Loading states — every data fetch should have a skeleton loader variant. Design the skeleton version of the Dashboard, Lesson Plan list, and AI Session chat
Empty states — design an empty state illustration placeholder for: No lesson plans yet, No AI sessions yet, No notifications, No pending approvals
